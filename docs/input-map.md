# Actions, keys and mouse targets

Generated by the `the_input_map_document_is_current` test from the keymaps and the mouse
targets the screens declare. Every action has a key. An action without a direct mouse
target is reached through the command palette (`:`), which every screen opens by click.

## Everywhere

| Action | Id | Keys | Mouse |
|---|---|---|---|
| Show the help | `global.help` | `?` | Click `[?] Help` on any screen |
| Open the command palette | `global.palette` | `:` | Click `[:] Palette` on any screen |
| Undo the last transaction | `global.undo-last` | `u` | Open the palette, click the action |

## Plan dialog

| Action | Id | Keys | Mouse |
|---|---|---|---|
| Confirm and write (Enter does it while Confirm has focus) | `plan.confirm` | `y`, `Enter` | Click Confirm |
| Cancel, nothing is written (Enter does it while Cancel has focus) | `plan.cancel` | `n`, `q`, `Esc`, `Enter` | Click Cancel |
| Move focus between the buttons | `plan.focus` | `Tab`, `Left`, `Right`, `h`, `l` | Click a button to choose it directly |
| Select a file | `plan.select` | `j`, `k`, `Up`, `Down`, `Home`, `End` | Click a file row |
| Expand or collapse a file's diff | `plan.expand` | `d` | Click a file row |

Every key the PRD lists in section 6.2 is built.
